DÚVIDAS

Perguntas frequentes

Estou com problemas no site. O que faço? +

Atualize a página e verifique sua conexão. Se o problema continuar, envie uma mensagem para o suporte.

Estou com problemas na minha conta. O que faço? +

Verifique seus dados de acesso e, se o problema continuar, entre em contato com nossa equipe.

Estou com problemas com minha carona. O que faço? +

Confira as informações da sua carona e, se precisar de ajuda, entre em contato com o suporte.

Encontrei um erro no site. Como posso avisar? +

Use o formulário e descreva o erro que apareceu na tela.

Como posso falar diretamente com o suporte? +

Preencha o formulário acima para entrar em contato com nossa equipe.
